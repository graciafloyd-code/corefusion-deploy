# 中科超创 CoreFusion 用户服务协议

生效日期：2026-06-05

本协议适用于用户访问和使用中科超创 CoreFusion 提供的 API 中转、模型调用、额度计费、令牌管理及相关服务。

## 1. 服务内容

CoreFusion 提供 OpenAI 兼容格式的 API 接入服务，用户可通过平台创建令牌、充值额度，并调用平台开放的模型能力。

平台服务包括但不限于：

- API Token 创建和管理
- 模型调用转发
- 额度计费和余额管理
- 请求日志和消耗统计
- 分销商/OEM 接入支持

## 2. 账号与安全

用户应妥善保管账号、密码和 API Token。因用户主动泄露、共享、转让或保管不当导致的损失，由用户自行承担。

如发现账号或 Token 存在异常使用、泄露风险或被盗用，用户应立即删除相关 Token 或联系平台处理。

平台有权根据安全风险暂停异常账号或 Token 的使用。

## 3. 额度与计费

平台采用额度计费方式。用户充值或由管理员分配额度后，可使用额度调用模型。

当前基础规则：

```text
1 元 = 10000 quota
最低充值金额：10 元
```

不同模型、用户分组或分销商等级可能适用不同计费倍率。具体价格以平台后台、双方约定或交付报价为准。

## 4. 合理使用

用户不得使用本服务从事以下行为：

- 违反适用法律法规的行为
- 侵犯他人知识产权、隐私权或其他合法权益的行为
- 生成、传播违法违规、有害、欺诈、骚扰、恶意攻击等内容
- 试图绕过平台鉴权、计费、限流或安全机制
- 对平台、上游服务或第三方系统进行攻击、扫描、滥用或异常高频调用
- 未经授权转售、出租、转让账号或 Token

如用户行为造成平台、上游服务或第三方损失，用户应承担相应责任。

## 5. 服务可用性

平台会尽力保障服务稳定，但不承诺服务绝对不中断。以下情况可能导致服务暂停或异常：

- 上游模型服务故障
- 网络链路异常
- 服务器维护或升级
- 不可抗力或第三方服务变化
- 用户余额不足、账号异常或 Token 被禁用

平台将尽合理努力恢复服务，并在必要时进行通知。

## 6. 退款与售后

充值、退款、补偿和售后规则以平台发布的充值与售后说明为准。已经实际消耗的额度原则上不支持退款。

因用户错误配置、Token 泄露、误操作或违规使用产生的消耗，平台原则上不承担退款责任。

## 7. 分销商责任

分销商应对其下游用户的管理、销售、售后和合规使用负责。分销商不得向下游用户承诺超出平台能力范围的 SLA、价格或模型可用性。

分销商下游用户产生的请求、消耗、风险和违规行为，平台有权追溯至对应分销商账号，并采取限额、禁用 Token、暂停账号等措施。

## 8. 数据与日志

为完成计费、排障、安全审计和服务优化，平台可能记录必要的请求信息，包括但不限于：

- 用户 ID
- Token 标识
- 模型名称
- 请求时间
- 消耗额度
- 渠道状态
- 错误信息

平台不会主动公开用户 Token、密钥或敏感配置。

## 9. 协议变更

平台可根据业务、法律法规或安全要求调整本协议。协议更新后，继续使用平台服务即视为接受更新后的协议。

## 10. 联系方式

如需咨询、售后或商务合作，请通过平台指定联系方式联系管理员。
