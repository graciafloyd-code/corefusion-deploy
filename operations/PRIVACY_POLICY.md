# 中科超创 CoreFusion 隐私政策

生效日期：2026-06-05

本隐私政策说明中科超创 CoreFusion 在提供 API 中转、额度计费和令牌管理服务过程中如何收集、使用、保存和保护用户信息。

## 1. 我们收集的信息

为提供服务，平台可能收集以下信息：

- 账号信息：用户名、邮箱、登录信息
- 安全信息：登录时间、IP 地址、设备和浏览器信息
- 业务信息：Token 标识、模型名称、请求时间、消耗额度、渠道状态
- 充值信息：充值金额、充值时间、处理状态
- 售后信息：用户提交的问题、工单、截图或沟通记录

平台不会在公开文档中展示真实 API Token、管理员密码或上游密钥。

## 2. 信息用途

收集的信息主要用于：

- 创建和管理账号
- 计算 API 调用消耗
- 展示余额和用量
- 排查调用异常
- 识别风险和防止滥用
- 完成分销商对账
- 提供售后支持

## 3. API 请求内容

平台作为 API 中转服务，可能在请求转发、日志记录和错误排查过程中处理用户提交的请求内容。

用户应避免在请求中提交敏感个人信息、商业秘密、账号密码、银行卡信息或其他不应交给模型处理的内容。

## 4. 信息保存

平台会在实现服务目的所需范围内保存必要数据。请求日志、充值记录和对账记录可能会保存一定时间，以便计费、审计和售后。

当数据不再需要时，平台可根据运营需要进行删除、匿名化或归档。

## 5. 信息共享

平台不会出售用户个人信息。

在以下情况下，平台可能共享必要信息：

- 为完成 API 调用向上游模型服务传递请求
- 根据法律法规、监管要求或司法机关要求提供
- 为处理安全事件、违规行为或争议所必要
- 经用户明确授权

## 6. 信息安全

平台采取合理措施保护用户信息和密钥安全，包括：

- HTTPS 加密传输
- Token 隔离
- 敏感配置隐藏
- 管理员权限控制
- 日志审计
- 服务器访问控制

但互联网服务无法保证绝对安全，用户也应妥善保管账号、密码和 Token。

## 7. 用户权利

用户可根据平台能力申请：

- 查看账号信息
- 修改账号资料
- 删除或重置 Token
- 查询用量和余额
- 申请注销或禁用账号

部分记录因计费、审计、争议处理或法律要求，可能无法立即删除。

## 8. 未成年人

本服务主要面向开发者、团队和企业用户。未成年人使用服务应取得监护人同意，并在监护人指导下使用。

## 9. 政策更新

平台可根据业务变化、法律法规或安全要求更新本隐私政策。更新后继续使用服务即视为接受更新内容。

## 10. 联系方式

如对隐私政策或数据处理有疑问，请通过平台指定联系方式联系管理员。
