# 手动充值与额度调整 SOP

本 SOP 用于试运营阶段线下收款后，管理员手动给用户或分销商增加额度。

## 1. 适用场景

- 普通客户充值
- 分销商预付款充值
- 测试额度发放
- 故障补偿额度
- 商务赠送额度

## 2. 充值前收集信息

```text
客户账号：
客户类型：普通用户 / 分销商
充值金额：
付款方式：
付款截图或交易号：
是否开发票：
备注：
```

## 3. 额度换算

当前规则：

```text
1 元 = 10000 quota
```

示例：

| 充值金额 | 增加额度 |
| --- | --- |
| 10 元 | 100000 quota |
| 50 元 | 500000 quota |
| 100 元 | 1000000 quota |
| 500 元 | 5000000 quota |
| 1000 元 | 10000000 quota |

## 4. 后台操作流程

1. 登录主站后台。
2. 进入用户管理。
3. 搜索客户账号。
4. 核对用户类型和分组。
5. 修改余额或执行充值操作。
6. 备注充值金额、付款方式和交易号。
7. 保存后刷新确认余额变化。
8. 通知客户额度已到账。

## 5. 分销商充值检查

分销商充值前需要额外确认：

- 是否为独立分销商用户
- 是否使用专属 Token
- 所属分组是否正确
- 可用模型是否正确
- 是否需要调整额度上限

## 6. 到账通知模板

```text
您好，您的额度已到账。

账号：
充值金额：
新增额度：
当前可用额度：
API Base URL：https://supchuang.com/v1

请注意妥善保管 API Token。
```

## 7. 异常处理

### 付款金额与申报不一致

先暂停加额度，与客户确认实际付款金额。

### 账号不存在

请客户先注册账号，或由管理员创建账号。

### 加错账号

立即记录操作，按实际情况扣回错误额度，并给正确账号补充额度。

### 客户要求退款

先核对额度是否已消耗。已消耗额度原则上不退款，未消耗部分可按售后规则处理。

## 8. 内部记录表字段

建议每笔手动充值都记录：

```text
日期
客户账号
客户类型
充值金额
增加额度
付款方式
交易号
操作人
备注
```
