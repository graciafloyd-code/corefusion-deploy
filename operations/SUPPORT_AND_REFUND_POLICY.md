# 充值、退款与售后规则

生效日期：2026-06-05

本规则适用于中科超创 CoreFusion 主站用户及分销商客户。

## 1. 充值规则

当前主站采用额度计费：

```text
1 元 = 10000 quota
最低充值金额：10 元
```

试运营阶段建议采用：

```text
线下收款 -> 管理员后台加额度 -> 用户或分销商使用
```

支持的线下收款方式可根据实际业务确定，例如微信、支付宝或对公转账。

## 2. 到账规则

用户付款后，应提供：

```text
账号：
充值金额：
付款截图或交易单号：
```

管理员确认收款后，在后台为用户添加对应额度。

建议处理时效：

```text
工作时间：30 分钟内处理
非工作时间：次日优先处理
```

实际到账时间以人工处理为准。

## 3. 退款规则

以下情况可申请退款：

- 付款后尚未到账且用户不再需要服务
- 付款金额错误，且尚未使用对应额度
- 平台原因导致长期无法提供服务，且双方协商一致

以下情况原则上不支持退款：

- 已经实际消耗的额度
- 用户 Token 泄露导致的消耗
- 用户配置错误导致的请求消耗
- 用户违反平台规则导致账号或 Token 被禁用
- 上游模型正常返回但结果不符合用户主观预期
- 赠送额度、优惠额度、测试额度

## 4. 故障补偿

如因平台自身原因造成服务长时间不可用，平台可根据影响范围提供补偿，包括：

- 延长服务周期
- 赠送额度
- 退还未消耗额度
- 双方协商的其他方式

上游模型服务、网络运营商、用户自身配置、第三方系统异常导致的问题，不默认纳入平台补偿范围。

## 5. 售后范围

平台支持以下售后：

- API 接入指导
- Token 创建和使用说明
- 余额和扣费查询
- 模型调用错误排查
- 分销商渠道配置指导
- 充值到账核对

平台不承诺提供以下服务：

- 替用户开发完整业务系统
- 保证模型输出完全准确
- 处理用户下游客户纠纷
- 保障任何上游模型永久可用
- 承担用户违规内容或滥用造成的责任

## 6. 工单信息模板

用户反馈问题时，建议提供：

```text
账号：
Token 名称：
调用模型：
请求时间：
错误信息：
请求 ID：
问题描述：
```

请勿在公开群聊中发送完整 API Token。

## 7. 分销商售后

分销商应优先处理其下游用户问题。涉及主站上游调用、额度扣费或渠道异常时，分销商可向主站提交排查信息。

主站根据分销商专属 Token 的日志进行核对。
